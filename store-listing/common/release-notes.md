# Release notes

## 1.0.0: first public release

Release date: `[TO BE DECIDED]`

Timesheet for Jira shows your Jira worklogs as a weekly timesheet and lets you change them from there.

**Weekly timesheet**
- Monday-to-Sunday view with daily and weekly totals, a card for each day, and week navigation.
- Each worklog shows the issue key (linked to Jira), the issue's status, its summary, your work description, the start time, and the duration.
- Worklogs are grouped by day in your browser's time zone.

**Working with worklogs**
- Log work on an issue from any of its worklogs in the week, with 15-minute, 30-minute, and 1-hour shortcuts. The date follows the day you select in the timesheet.
- Edit a worklog's date, start time, duration, and work description.
- Delete a worklog after a confirmation showing the issue, date, and duration.
- Totals update as soon as Jira confirms a change. If Jira refuses a change, the reason is shown and nothing in the timesheet changes.

**Connection**
- Jira Cloud with account email and API token, and Jira Data Center / Server 8.14 or later with a personal access token.
- Separate saved settings for each edition, and a **Test Connection** check.

**Other**
- Light and dark themes.
- Works in Chrome and in Firefox 116 or later.
